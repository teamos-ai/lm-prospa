What moves this number most

Each row changes one assumption and holds the rest. It is the fastest way to see which lever is actually yours to pull.

The question behind the number

If your target age is earlier than the age you can access super, the issue is not only how much wealth do I need. It is also where that wealth needs to sit, and when it has to be reachable. A large balance behind a preservation date does not fund the years before it.

Important limitations. This is a simplified educational illustration, not a retirement forecast. It ignores tax, fees, investment volatility, the order in which returns arrive, changes in spending, superannuation, the age pension, other assets and many further factors. The withdrawal rate is a planning assumption, not a recommendation or a guarantee, and returns are not guaranteed. Moneysmart's retirement guidance notes that what you need varies with the lifestyle you want, and that planning should consider when super can be accessed and how any income gap is funded — moneysmart.gov.au.
